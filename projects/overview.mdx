Use a project for a recurring review, team initiative, or investigation. A “Monthly business review” project can hold the analysis chat, dashboard, and presentation for that review.

## Before you begin

Create the project in the workspace where the work belongs. You need permission to create projects or add items, and access to the resources you want to use.

## Create a project

1. Use **New project** beside **Projects** in the sidebar.
2. Give it a descriptive name and choose a folder color.
3. Review **User Access** and choose who should have access.
4. Select **Create project**, then open it from the sidebar.

## Work inside a project

The project's home includes the Analyst message box and four tabs:

| Tab | What belongs here |
| --- | --- |
| **Chats** | Conversations associated with the project |
| **Artifacts** | Dashboards, Datasites, automations, and generated files |
| **Query Bench** | Saved queries used by the project |
| **Agents** | Agents associated with the project |

Ask a question from the project's message box to start a chat in that project. Use the tabs, search, and ownership filters to find existing work.

## Add existing work

Use an item's **⋯** menu to assign it to a project where you can add items. When using **New Artifact**, choose the project in the form before building.

The item then appears in its project tab. Organizing a query or agent in a project does not replace its data configuration.

## Share and manage the project

Open **Share** on the project's home to review direct and inherited access.

| Project access | What it allows |
| --- | --- |
| **Can view** | Open the project and its items; read its chats |
| **Can chat** | Also start project chats and ask questions about its chats and dashboards |
| **Can edit** | Also change existing content and shared context |
| **Can create** | Also add items and create new ones in the project |

Changes also require an editing role in the workspace. Only the project owner can rename, share, or delete the project.

Review the project's audience before adding work, because its access can carry through to items inside it. If an action is unavailable, ask the owner to check the Share settings.

## Next steps

Your project is ready when related items appear in its tabs and the intended teammates have access. [Manage chats](/analyst/managing-chats) or [create an artifact](/artifacts/overview) for your next task.
