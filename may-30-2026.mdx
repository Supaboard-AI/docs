## Automation — New Capabilities &amp; Reliability

### Ask Questions Over a Dashboard

Automated tasks can now include an "Ask Dashboard" action — point it at any dashboard and give it a prompt, and it answers questions using that dashboard's latest widget data. Great for turning a recurring question ("did revenue drop this week?") into a fully automated check.

### More Flexible Data Passing Between Steps

Automation templates can now pull whole columns or multiple rows from an earlier step's results, not just a single value — so you can combine data across steps to build more sophisticated multi-step workflows.

### Smarter Email Step

The email action's "To" field is now a dropdown pre-filled with your team's active members, so you no longer have to type addresses by hand.

### More Reliable Test Runs

Testing a task before deploying it now automatically runs any upstream steps it depends on, so you can validate a downstream step without running the entire automation first.

### Bug Fixes

- Fixed an issue where valid automations could incorrectly fail with a "cycle detected" error
- Fixed a bug where automations referencing query results in later steps could fail to resolve those references
- Fixed a rare issue where some scheduled automations could run their actions (e.g. emails) more than once
- Fixed autosave, step-insertion ordering, and the variable editor in the automation builder so edits save reliably and referenced variables display correctly

## Mini-Board

Admins can now bulk add users to a mini-board directly, without sending individual email invites — useful for quickly provisioning a large group of viewers.

---

## Search &amp; AI Answers

Ask-AI answers no longer show stale or duplicate widgets — when the AI corrects a chart or table it generated, only the corrected version is shown.

## Dashboards

- Fixed an issue where custom date ranges weren't showing up in dashboard filters
- Fixed an issue where dropdown/enum options could incorrectly show as empty
- Improvements to map charts, donut charts, axis rendering, and right-click context menus on widgets
