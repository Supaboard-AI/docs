You work inside a **workspace**, ask questions through the **Analyst**, and keep outputs as **artifacts**. Use **projects** to organize related work.

## How everything fits together

| Part of Supaboard | What it means | Where to go |
| --- | --- | --- |
| Workspace | Your team's environment, members, and settings | Workspace menu and Settings |
| Data sources | Connections to the data you want to analyze | Data sources; Settings → Connections |
| Agents | Assistants with a data scope, business rules, and knowledge | Agents |
| Analyst | The chat where you ask questions and build outputs | Home or New |
| Artifacts | Dashboards, Datasites, automations, and generated files | Artifacts |
| Projects | Related chats, artifacts, queries, and agents | Projects |
| Query Bench | An editor for working directly with queries | Query Bench |

## Workspace

A [workspace](/workspace/overview) contains your team's connections and work. You can belong to more than one workspace. Switch from the workspace menu; what you can see and change depends on your access in that workspace.

<span id="2-data-sources" />

## Data sources

A [data source](/data-sources/overview) connects Supaboard to data stored elsewhere. Administrators manage connections in **Settings → Connections**. **Data sources** lets you browse and explore connected data.

<span id="5-ask-stella" />

## Agents and the Analyst

An [agent](/agents/overview) defines what data an assistant can use and how it understands your business. The [Analyst](/analyst/overview) is where you talk to that agent. Choose the agent and a mode—Flash, Pro, or Max—in the message box.

Older documentation calls this experience **Ask Stella**, **Ask Agents**, or **Ask Analysts**. Start from **Home** in the current app.

## Artifacts and widgets

An [artifact](/artifacts/overview) is something you can return to, edit, and use beyond an individual answer:

- **Dashboard:** pages of charts, tables, metrics, and other widgets. A dashboard group holds related dashboard pages.
- **Datasite:** an interactive site built around your data, with its own layout and publishing controls.
- **Automation:** a workflow that runs on a schedule or when an alert condition is met.
- **File:** a generated output, such as a report or presentation.

A **widget** is an individual chart, table, KPI, or other content block. Widgets appear in answers and dashboards; they are not the same as a whole artifact.

## Projects

A [project](/projects/overview) brings related chats, artifacts, saved queries, and agents together. For example, a “Monthly business review” project can hold the analysis chat, dashboard, presentation, and queries for that review.

Projects organize work across features. Dashboard groups organize pages within a dashboard.

## Other things worth knowing

- Use [All chats and Pinned](/analyst/managing-chats) to return to conversations.
- [Workspace permissions](/workspace/overview#roles-and-permissions) and each resource's sharing settings determine access. Check project membership before adding work to a project.
- [MCP tools](/agents/tools) let agents use connected services. [Slack](/analyst/integrations/connect-supaboard-to-slack) and [Claude](/analyst/integrations/connect-supaboard-to-claude) are other places you can ask Supaboard questions.
- [White labeling](/workspace/white-label) provides a branded Supaboard experience. [Dashboard embeds](/dashboards/embedding/overview) place a dashboard inside another website or product.
