## Table Widgets: Column Grouping &amp; Aggregate Footers

- **Group Columns**: Organize related columns under a named, colored group band that spans the header — great for tables with lots of columns that fall into natural categories
- **Aggregate Footers**: Add per-column summary rows (SUM, AVG, MIN, MAX, COUNT, COUNT DISTINCT) with optional custom labels, so totals and averages are visible without leaving the table
- **Expand Groups by Default**: Choose whether grouped rows start expanded or collapsed
- **Per-Level Header Colors**: Nested row groups can now have their own header color per level, making deep groupings easier to scan
- Group and aggregate configuration is shared across Dashboard, Ask Stella, and Query Builder tables, so your setup carries over wherever the table appears
