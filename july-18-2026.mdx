## Filter Dashboards by Clicking a Table Value

You can now right-click any cell or row in a table widget and instantly filter your dashboard by that value — no need to open a filter widget and search for it manually.

- Works across categorical, string, numeric, boolean, and date columns, each handled with the right filter logic (e.g. clicking a date filters to that day, clicking a category filters to just that value)
- Automatically matches the clicked column to the right filter fields on your dashboard, even when multiple filter widgets could apply
- Updates all affected filters together in a single step, so your dashboard doesn't flicker through intermediate states

### Column Source Mapping

Sometimes a table's column doesn't share an obvious name or source with your dashboard filters — for example, an aliased or renamed column. A new "Column Source Mapping" option in the table's customization panel lets you manually map a table's columns to the correct underlying data source, so click-to-filter keeps working correctly even in these edge cases.
