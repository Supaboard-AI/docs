## Meet the Analyst: A New Home for Asking Questions

Supaboard now opens on the Analyst, a chat that replaces Ask Stella. You can ask it a question, have it dig into the data, or have it build something, all from one place. Your Ask Stella conversations are still here and open in the new chat.

- The home screen greets you and shows suggested builds for the selected agent, along with your recent chats and artifacts
- Answers stream in as they're written. Insight findings appear one at a time as the agent confirms them.
- The thought stream shows each step the agent takes: what it's working on, which tools it called, and how long each query spent in your database. A status line at the bottom shows elapsed time and tokens used.
- A turn keeps running if you close the tab or reload. Come back and it picks up where it is. Only **Cancel** stops it.
- Web search is available on every turn
- In **Max** mode, the agent posts a plan checklist before it starts running queries

### Flash, Pro and Max

The mode picker in the chat box is now a three-stop slider. Your chosen agent and mode are remembered for the session. Switching agents no longer clears what you've typed, your attachments or your context chips.

### Attachments and Context

- Attach files to a question. Images show as thumbnails and documents as named cards. The agent previews CSV and Excel files, and it reads large PDFs and slide decks page by page as it needs them.
- Add artifacts or uploaded files as context for a chat. Several context items collapse into a single chip.
- Each question in the thread shows the items and files it was sent with
- Press Tab or → in an empty chat box to accept the suggested follow-up

### Working with Answers

- Every chart, table and KPI in an answer has **Edit**, **Pin** and **Open**. More actions are in its ⋯ menu.
- Tables in answers have a scrollbar that's always visible and tooltips with the full column name. Select cells to see their count, sum and average. Copying includes the column headers.
- Widgets pick up the right number format, so values read as "59.7%" or "$4.2M" and a KPI showing 17.71 no longer rounds to "18"
- The agent gives one widget per result and doesn't repeat a chart as a table unless you ask

### Search and Sharing

- **All chats** search now runs across every conversation, including older Ask Stella ones. Matches rank by title, then your prompts, then the answers.
- Share a chat from the **Share** button in the top bar. The person who created it decides who can open it.
- Only the creator can rename, re-share or delete a chat

## Like and Dislike Teach the Agent

Each widget's ⋯ menu now has **Like** and **Dislike**.

- A dislike asks what was wrong. Your note becomes a correction the agent applies for everyone who uses it, and the queries and memories behind that answer are removed.
- Click again to take your reaction back
- Only people who can use an agent can change it this way

---

## Fewer Approval Prompts

The Analyst asks for approval only before actions that are hard to undo or that reach the outside world:

- Publishing a datasite
- Turning an automation on
- Test-running an automation or one of its steps
- Write actions through MCP connections, and requests to web addresses that came from a web page, document or MCP result

Everything else just runs, including read-only MCP tools like Notion search, which asked every time before.

**Allow** is also more reliable now. If your tab drops right after you click it, the turn continues instead of getting stuck.

## Build Artifacts from Chat

Ask the Analyst to build a dashboard, datasite, automation, document or connection. It shows up as a card in the answer, and the card opens in a side panel.

- **Dashboards:** add and update charts, KPIs, text, images and embeds. Set filters and layout, and add, reorder or rename pages. You can watch each change in the panel as it happens.
- **Dashboard embeds:** create and manage embeds from chat with every setting the Embed panel offers. The agent gives you the link and the iframe code.
- **Datasites and automations:** built and edited in a live editor next to the chat. The artifact is locked with an "AI is currently editing" guard while the agent works on it. Datasites wire their numbers to saved queries rather than hardcoding them. Published datasites get a built-in chat launcher.
- **Documents:** create and edit PDFs, presentations and spreadsheets, or match the style of a file you upload. Decks now use a 12-column grid, and the agent can generate images and infographics for them.
- **Connections:** ask to "connect my Postgres" or "connect Asana" and you get a **Connect** button that opens the right form. The agent never creates a connection on its own.
- **Clarifying questions:** before a larger build, the agent can ask you a question in plain text or show you its plan to review
- Follow-ups like "make this a line chart" keep working on the same artifact

## Projects and Artifacts

New pages to organize your work: **Artifacts**, **Projects**, **All chats** and **Pinned**.

- A project holds its chats, artifacts and context files. Anything created in a project chat is filed there automatically.
- Project items are visible only to project members and workspace admins
- A project's **Artifacts** tab lists the PDF, PPT and XLSX files filed in it
- Clicking an artifact opens it. **Edit in chat** opens a chat with the artifact docked beside it.
- Dashboards, automations and datasites share a single header with a breadcrumb you can rename inline. Dashboards get **Insight AI** and **Edit with AI**, and **Edit manually** is in the ⋯ menu.
- The datasite page puts the chat on the left and the site on the right
- Favorites work on every library page

## A Redesigned App

- **Sidebar:** projects, chats and folders in one tree. You can resize it on every page, and it no longer collapses on its own. When it's collapsed, every page header has a button to open it again. A dot blinks next to any chat that's still answering.
- **New button:** it's styled as a keycap now, and it clicks when you press it
- **Settings** opens as a modal over the page you're on, and old settings links still work. **Tools** now lives under Settings.
- **Command palette:** Create actions open the new-artifact popup on the right tab, and Ctrl+K works on Windows and Linux
- Page headers are aligned across the app, and agents have animated faces in the chat
- Library tiles show agent and data-source icons. The Agents page and the Query Builder home were redesigned.

## Charts and Maps

- **Maps rebuilt:** region maps color by quantile, gradient or custom steps, gray out areas with no data, and can zoom to your data. State maps work for any country, and cities and states are resolved worldwide. A split column shows as groups inside a single map, with mini bars or pies on pin maps.
- **Funnels redesigned:** centered bars, vertical or horizontal, with one lane per measure. Funnels use the chart color palette.
- The legend now sits under the chart title. Edits you make in chart settings last for the session and are what gets pinned.
- **Dashboards:** the **Add Widget** dialog has a **Chats** tab that lists widgets from your Analyst chats. The select-from-collection popup was redesigned with previews and filters.

## Faster, More Accurate Answers

- Read queries in one step now run in parallel, so four 8-second queries take about 8 seconds instead of 32
- Turns start sooner and resend less to the model. Large query results are paged instead of sent whole.
- Paginated queries on SQL sources skip the extra count when the page already shows the total
- Numbers in insights have to cite real query results. Ranking claims like "top 3" are checked against every row.
- A second pass checks the SQL against your workspace rules, preferences and agent memories before the answer goes out
- Data queries time out after 90 seconds, with a hint on how to narrow the query
- More read-only SQL functions are allowed on Oracle, Redshift, ClickHouse, Databricks and DuckDB

## Fixes

- Tightened workspace and conversation access checks
- MCP tools from Gmail, HubSpot and other apps whose inputs use schema definitions now run. Tool errors are reported as errors, and a slow MCP server is skipped after 8 seconds instead of holding up the turn.
- Pro and Max deep dives no longer lose their findings, and dashboard builds no longer end in "could not complete a verified answer"
- The agent no longer treats a date column's stored end date as the point where your data stops
- Formulas in answers show as plain text, and numbered lists that span headings render correctly
- Re-rendering an unchanged document says "unchanged" instead of claiming it was edited
- The Flash/Pro choice no longer flips back after the page loads
- If an answer fails to finish, the chat no longer shows it as a success. The chat box unlocks while an artifact is still building.
- Fixed a crash when renaming a dashboard group
