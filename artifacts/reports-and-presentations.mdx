title: "Reports and presentations"
description: "Turn an analysis into a PDF report or presentation you can review and share."
---

Ask the Analyst to prepare a report or presentation from your data or an existing analysis. Describe the audience, time period, and decisions the output should support.

## Before you begin

Choose an agent with access to the relevant data. If the output should use an existing dashboard, analysis, or reference document, add it as context.

## Create a report or deck

1. Start a chat, or continue the conversation containing the analysis.
2. Ask for the output you need. For example: “Create a presentation for our monthly business review. Compare last month with the previous month, explain the three biggest changes, and end with proposed actions.”
3. Answer any clarifying questions and review the generated file card.

You can also use **Artifacts → New Artifact → PDF** or **Deck**. Add a name, description, and optional project, then choose **Build with AI**. These file types have no manual creation option in that dialog.

## Review and revise

Open the output from its chat card. Check figures, dates, definitions, and presentation before sharing.

Request changes in the same chat: “Use our uploaded deck as a style reference,” “Add a slide on retention,” or “Shorten this to a one-page summary.” Keep the relevant file or artifact in context so the Analyst knows which output you mean.

## Find and download the file

Generated documents appear in **Artifacts → Files**. They also appear in the project's **Artifacts** tab when associated with a project. Open the file and use its download control to save it.

## Export or schedule a dashboard report

For a one-off output, follow [Export a dashboard report](/dashboards/how-to/export-dashboard-reports). For repeated delivery, use [Schedule dashboard reports](/automations/schedule-dashboard-reports).

## Access

**Can view** allows opening, downloading, and adding a file as chat context. **Can edit** also allows revising it with AI and exporting it again, subject to workspace editing permission. Only the owner manages sharing.

## Next steps

Your report is ready to share once you have reviewed its content and downloaded the intended version. Keep the analysis and output in a [project](/projects/overview), or return to the chat for the next revision.
