## Reports and Exports

Report generation got a larger overhaul this cycle.

- **Filter values in the report panel**: configure dashboard filter values while generating a report, so the export reflects the data slice you want without touching the live dashboard first
- **Format and theme**: export as PDF or PowerPoint, and pick a visual theme — Mocha, Kraft, Vortex, Dialogue, Pearl, or Default Dark — with live thumbnail previews
- **Custom instructions**: add a prompt to the deck generation form to tell the AI what to emphasize, what tone to use, or how to structure the narrative for a given audience
- **Advanced slide controls**: set a fixed number of slides, or describe each slide individually for precise control of deck structure
- The Generate Report form now opens as an overlay, so you keep your place in the decks list while creating

## Dashboards

- Dashboard, agent, query builder, and data source cards were redesigned: consistent styling, cleaner typography, thumbnail previews, and smoother hover states
- Drill-downs now respect active dashboard filters, so drill modals no longer show blank or misleading data
- Shared and embedded dashboard URLs can carry pre-configured filters — recipients open the dashboard on the exact data slice you intended
- Widgets accept custom border styles, colors, and radius, and backgrounds can be reset to the dashboard default
- KPI widgets support custom filters, with better handling of edge cases

## Drill-Downs and Data Exploration

- When you drill into a chart, the AI rewrites the underlying query to surface the most relevant raw records. This works across PostgreSQL, Snowflake, BigQuery, MySQL, Redshift, ClickHouse, Databricks, Azure SQL, and MongoDB, scores each rewrite for fidelity to your original intent, and applies correct date formatting for time-series drills.
- When a selected data point doesn't carry explicit metrics, the AI derives them from the selection instead of stopping
- Charts can toggle between standard and pivoted views, and pivot configurations are saved per widget across sessions
- Chart, KPI, and table drill-downs now propagate the underlying SQL correctly, so the records in the drill modal match what you clicked

## Automations

- **Email actions**: automated tasks can send email, with dynamic recipients pulled from your dashboard data and rich-formatted subject and body — built for alerts, summaries, and stakeholder updates
- **Report actions**: generate PDF and PowerPoint reports inside an automation, formatted via the Gamma integration, with the option to generate files without auto-delivery for custom downstream steps
- **Multi-step tasks**: input bindings let one task's output feed the next task's input
- Actions and triggers run on separate dedicated runners, database operations are async, and every job execution is logged for compliance and debugging
- A dry-run endpoint tests a task's full execution path without committing changes
- The default polling interval for scheduled tasks went from 30 seconds to 5 minutes, cutting infrastructure load without hurting responsiveness

## Search and Conversations

- Your first message creates its sidebar conversation entry instantly, with an AI-generated title
- The Thoughtstream shows which agent is responding instead of a generic label
- Follow-up questions are generated and surfaced with search results, and multi-turn context handling is more reliable
- The RAG pipeline was refactored for accuracy; answers are structured to keep insights evidence-backed, and results include timing information so slow queries are easy to spot

## Database Connectivity

- Schema understanding updates incrementally — no full re-sync needed after a change
- Better source attribution for tables ingested via Fivetran
- Dashboards can query pre-aggregated materialized views
- Query Builder: smarter table inference and target selection, consistent table enumeration across database types, and named lookup for cleaner API usage
- BigQuery: fixed row normalization for non-standard response formats, and SQL generation moved to a newer model

## Fixes

- Custom chart colors apply correctly when filters produce null grouping keys
- Pivot and grouping metadata syncs from API responses, preventing stale configurations
- Table widgets: schema sync only triggers on actual query changes, not background auto-refreshes, and the stored schema is the source of truth — no more unexpected column resets
- Row expander configurations clean up automatically when their related question widgets are deleted
- "View Records" is hidden in KPI right-click menus, since KPIs drill down but don't browse arbitrary records
- Invite links for individual users can be copied from the Share Dashboard panel
- Data source cards show connector display names alongside logos, and table counts are capitalized correctly
