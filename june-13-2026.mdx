## Reports: PDF Export

You can now generate reports as PDF, not just PowerPoint. Pick PDF when generating a report from a dashboard, from search, or as part of an automation — the same AI-driven layout and data-binding you already get with PPTX decks now applies to PDF output too.

---

## Automation Emails, Redesigned

Emails sent from automated tasks now use a cleaner, branded template:

- A header bar with your workspace logo and name
- A clearer body layout for the automation's message
- A consistent footer with Supaboard branding and social links

---

## Query Builder Improvements

- **Faster edits on large databases**: Query generation and fixes on workspaces with hundreds of tables are dramatically faster — turns that used to take up to 3 minutes now typically complete in well under a minute.
- **Friendlier error messages**: If query generation hits a temporary provider issue, you'll now see a clear, plain-language message instead of a raw internal error.
- **Schema refresh now applies immediately**: After refreshing a table's schema, the query builder immediately picks up the new columns instead of continuing to use stale schema information.

---

## Bug Fixes

- Fixed pagination in data views and custom query snippets — paging through records with filters applied no longer returns overlapping or duplicate rows.
- Fixed a bug where filtering on tables named after reserved SQL keywords (e.g. a table called `order`) caused custom query snippets to fail with a server error.
- Fixed a bug in the automation copilot where AI-created workflow nodes could end up with a blank title.
