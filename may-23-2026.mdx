## Knowledge Base: Interactive Graph View

The Knowledge Base for agents now renders as a live, interactive graph instead of a static list.

- Hover any file's chunks to preview their real content in a tooltip
- Click a file node to open it, or drag it to reposition it around the hub
- Zoom in/out/reset, pan, and use your trackpad or scroll wheel to navigate
- Delete files directly from the sidebar with a quick confirmation

---

## Ask AI: More Accurate Answers, Faster Exports

- Ask AI now writes correctly-qualified SQL against your actual database schema instead of occasionally guessing at table names — fewer failed queries, faster answers
- "Make a PPT out of this" now reuses the data already on screen instead of re-running your query from scratch, so exports are faster and match what you were just looking at
- AI-generated summaries render as clean prose instead of occasionally leaking raw formatting into the response

---

## Automations

- Fixed: deleting an automation and rebuilding it with the same name no longer fails with an "already exists" error — leftover steps from the old automation are now properly cleaned up
- Improved reliability of field references between chained steps, so the fields you can bind to from an earlier step's output are now shown accurately
