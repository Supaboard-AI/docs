## Agent Skills

Agents can now be taught reusable **skills** — packaged instructions that shape how they handle particular kinds of tasks. Each agent gets a new Skills page where you can:

- **Create skills three ways**: write one directly in the app, upload an existing skill file (`.md`, `.zip`, or `.skill`, including bundled resources), or have the AI create and refine one with you through chat
- **Manage everything in one place**: search, filter, and sort your skills; open a detail panel with a full markdown preview; enable, disable, or delete a skill in a click
- **Let agents manage their own skills**: while chatting, you can ask an agent to list, create, edit, or delete its skills — changes show who made them

## Databook Improvements

- **Pin dashboard widgets** to a datasite so live charts from your dashboards appear alongside generated content
- **Edit glossary items with AI** instead of rewriting them by hand
- **Stop button** to interrupt a generation mid-run
- **Resilient chat streams**: conversations now reconnect automatically, so a page reload or dropped connection no longer loses a running build
- **Attachments**: share files and images with the analyst, with a cleaner attachments experience and a live step log while it works
- **Environments**: manage separate environments for a datasite, with more reliable hosting behind the scenes
- Editor polish throughout, including a redesigned file tree and chat experience
