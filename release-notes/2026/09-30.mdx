**September 30, 2026** · Covers September 26–30, 2026.

## Improved

- **Choose how you browse your work.** Library pages offer a grid or a sortable table, so you can scan previews or compare items in a list. [Find artifacts](/artifacts/overview).

- **Share with clearer access controls.** Sharing follows a more consistent pattern across chats and artifacts. Choose who can access an item and the permissions available for that type of work.

- **Choose an agent and a mode together.** The chat composer brings agent selection and **Flash / Pro / Max** into one menu. [Ask the Analyst](/analyst/overview).

- **Review actions before allowing them.** Approval cards make **Deny**, **Allow once**, and **Always allow** easier to distinguish when an action requests permission.

- **Configure and try an agent in one place.** Agent settings organize knowledge, tables, examples, memory, and evaluations into tabs. Use **Try in chat** to test your changes. [Configure agents](/agents/overview).

- **Fit a table column to its contents.** Double-click a column header to widen it to fit the visible contents.

## Fixed

- A link to a specific chat message jumps to that message more reliably, and repeated artifact cards are removed from affected answers.

- Completed analysis results remain available if writing the final response fails. The assistant can also recover from more failed queries.

- Deleting an artifact updates the interface more consistently, and text between `<` and `>` remains visible in your messages.
