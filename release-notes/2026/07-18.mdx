## Improved

- **Ask questions using the dashboard’s existing results.** The assistant makes better use of dashboard widgets before querying the underlying connection for additional information. [Dashboard insights](/dashboards/insights-in-dashboard).

## Fixed

- **Keep related filters in sync.** Filters whose available choices depend on another selection now update more reliably, including in embedded dashboards. [Dashboard filters](/dashboards/filters/how-to-add-filters-to-your-dashboard).

- HTML results show a loading state while their content is being prepared.
