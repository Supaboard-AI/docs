## New

- **Click a value to filter the dashboard.** A table can become the starting point for exploring related charts. Set up the column mapping so the selection applies to the correct data. [Filter dashboards from a table](/dashboards/filters/filter-dashboards-from-table-data).

- **Choose how a table opens.** Set its initial page and rows per page, or hide the pagination footer. [Table settings](/dashboards/widgets/table-widget).

## Improved

- **Choose automation email recipients from earlier results.** An email step can use recipient values produced by another step.

## Fixed

- Clicking a table column without a filter mapping no longer applies an unintended dashboard filter.

- Password-reset failures show a useful error message.
