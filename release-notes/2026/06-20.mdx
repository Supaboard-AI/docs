## New

- **Wrap long column headings.** Turn on **Wrap header titles** in table settings to show the full name without making every column wider. [Table settings](/dashboards/widgets/table-widget).

## Improved

- **Explore grouped tables with less clicking.** Expand all groups and move through pages of grouped results.

- **Export the current table view.** CSV exports respect active filters, visible columns, and the column order you chose.

## Fixed

- Timestamp labels display correctly in the affected charts.

- Refreshing a data source makes its updated table structure available immediately, and browsing later pages of records no longer skips the wrong number of rows.
