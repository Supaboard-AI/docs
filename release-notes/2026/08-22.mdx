## New

- **Repeat steps for each item.** Add a loop to an automation and preview individual iterations when testing it. [Automations](/automations/overview).

- **Manage an agent’s connected tools.** Supported MCP connections can use a sign-in flow. Review their connection status, enable or disable individual tools, and disconnect an app when it is no longer needed. [Connect tools](/agents/tools).

## Improved

- **See workspace usage and set limits.** Workspace controls make it easier to review usage and manage limits for members. [Usage and billing](/workspace/usage-and-billing).

- **Export a dashboard with a shortcut.** Use **⌘P** on Mac or **Ctrl+P** on Windows to open the dashboard snapshot action.

## Fixed

- Canceling an AI response keeps the results that were already completed.

- Date filters on MongoDB data return the expected records in the affected filtering flow.
