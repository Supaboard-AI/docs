## New

- **Start with the Analyst on Home.** Ask a question or describe something to build from one place. Choose **Flash**, **Pro**, or **Max**, attach files, and add existing work as context. [Ask the Analyst](/analyst/overview).

- **Keep related work in a Project.** Bring chats, artifacts, and context files together around a task or team. [Organize a Project](/projects/overview).

- **Find what you have created in Artifacts.** Open saved work from a shared library and continue editing it in chat. [Find and manage artifacts](/artifacts/overview).

## Improved

- **Work directly with results.** Open, edit, or pin charts, tables, and KPIs from an answer. Feedback controls let you mark a result as helpful or explain what went wrong. [Understand answers](/analyst/insights-in-ask-agents).

- **Find an earlier conversation.** Chat search looks through conversation titles, your questions, and the answers. [Manage chats](/analyst/managing-chats).

- **Create a Datasite using existing dashboard work.** The builder can reuse a dashboard as a starting point for the site.

- **Explore data with updated maps and funnels.** Both visualizations have been rebuilt for the new analysis experience.

- **Change settings without leaving your work.** Settings opens over the current page, making it easier to return to what you were doing.

## Fixed

- Interrupted chats recover more reliably, and a lost connection after approval no longer leaves the request stuck in the affected flow.

- KPI results preserve the intended number format and decimal precision.

- The exhausted-allowance banner no longer appears incorrectly when usable purchased balance remains.
