## New

- **Create a Datasite.** Describe the experience you want, preview it as it is built, and publish or embed it for your audience. Datasites bring interactive pages and connected data together. [Create a Datasite](/datasites/create-a-datasite).

## Improved

- **Stay in control while a Datasite is being built.** Stop a build when you need to change direction.

- **Refine a presentation through follow-ups.** Ask for changes to an existing deck and use an uploaded reference to guide its style. Chart data and large tables are handled more reliably. [Reports and presentations](/artifacts/reports-and-presentations).

- **Get help setting up an agent.** Suggested answers make the setup questionnaire easier to complete. [Set up an agent](/agents/set-up-an-agent).

## Fixed

- PostgreSQL connections include a database named `postgres` when discovering available databases.
