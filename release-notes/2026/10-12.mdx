**October 12, 2026** · Covers October 1–12, 2026.

## New

- **Work with spreadsheets in Sheets.** Create a spreadsheet, import a workbook, edit cells and formulas, and share or export the result. Choose workspace storage when creating the first spreadsheet. [Use Sheets](/sheets/overview).

- **Put an agent chat on your website.** Set up a service account and server-issued tokens, then add the chat widget to your pages. [Add website chat](/agents/embed-an-agent).

## Improved

- **Turn uploads into editable data.** Spreadsheet attachments become Sheets that the default agent can query. Files and artifacts created in a project chat stay with that project. [Attach context](/analyst/overview#files-and-artifacts).

- **Choose a chart that fits the question.** The chart picker groups compatible chart families by purpose, with new options for rankings, distributions, relationships, and flows. [Configure charts](/dashboards/widgets/chart-widget).

- **Build richer KPI cards.** Choose Number, Change, Progress, Trend, Breakdown, or Multi, then map result columns in Data and format the card in Display. [Configure KPIs](/dashboards/widgets/kpi-widget).

- **Refine dashboard text and layout.** Format text blocks with the floating toolbar and review the layout before saving. [Edit a dashboard](/dashboards/how-to/edit-a-dashboard).

- **Open Datasites as previews and edit in chat.** Direct in-app links open the preview workspace. Choose Edit with AI to continue building beside an Analyst conversation. [Create a Datasite](/datasites/create-a-datasite).

- **Keep your preferred agent and give clearer feedback.** Use Make default for new chats and rate finished answers from 1 to 5 when prompted. Agent memory distinguishes Must-have, Preference, and Suggestion. [Configure agents](/agents/overview).

- **Start on Free and review storage usage.** New workspaces start on a Free plan with a one-time AI allowance. Paid plans offer monthly or annual billing, and managed storage usage is visible alongside plan details. [Review billing](/workspace/usage-and-billing).

## Fixed

- Dashboard widget queries apply saved dashboard filters, and an empty data source no longer leaves chat waiting indefinitely for a sync.

- Sheets supports more reliable AI undo, saved filter views, and edits involving formulas. A weaker memory no longer replaces a stronger instruction.
