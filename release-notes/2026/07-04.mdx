## New

- **Build an automation by chatting.** Describe the workflow you need and work with the AI assistant to build its steps. [Create an automation](/automations/create-an-automation).

- **Schedule dashboard reports.** Choose the recipients, timing, filters, and report format, including Excel. You can also send a summary without a report attachment. [Schedule dashboard reports](/automations/schedule-dashboard-reports).

- **Take a dashboard snapshot.** Export the dashboard as a PDF with the data and filters in the current view. [Export dashboard reports](/dashboards/how-to/export-dashboard-reports).

## Improved

- **Keep filters when building with AI.** Automation steps created from a dashboard use its actual filters.

## Fixed

- Weekly and monthly schedules use the selected timing more reliably.

- A failed AI summary no longer makes successfully fetched data appear to be empty.
