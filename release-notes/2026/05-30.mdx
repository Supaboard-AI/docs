## New

- **Explore an agent’s knowledge visually.** An interactive graph shows how items in its knowledge base relate to each other. [Configure an agent](/agents/overview).

## Improved

- **Read clearer AI summaries.** Answers use cleaner prose, and the assistant can recover from more situations where a clarification previously led to a dead end.

## Fixed

- AI-generated queries identify database tables by their actual names, reducing failures caused by an incorrect table reference.

- Fivetran setup no longer creates duplicate data sources in the affected connection flow. [Connect with Fivetran](/data-sources/connectors/fivetran).

- Connection setup accepts display names containing spaces, and upgrade prompts no longer appear repeatedly in the connector flow.
