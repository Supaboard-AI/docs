## New

- **Let an automation ask about a dashboard.** Add a step that uses the dashboard to answer a question. [Create an automation](/automations/create-an-automation).

- **Choose a path based on a result.** Conditional branches let an automation take different next steps when its conditions are met.

## Improved

- **Edit with fewer interruptions.** Automation changes save automatically, and you can insert a new step between existing steps.

- **Pass more than one value between steps.** Use a whole column or multiple rows from an earlier result. Choose workspace members more easily when setting up an email step.

- **Test a step with the inputs it needs.** Required earlier steps run before the selected test step.

- **Explore more PostgreSQL data.** Materialized views are available alongside your other database tables and views.

## Fixed

- Scheduled automations avoid duplicate runs in the affected scheduling flow, and deleting an automation also removes its leftover steps.

- Drilling into grouped results respects combined filter conditions more accurately.
