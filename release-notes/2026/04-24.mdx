## Improved

- **Tailor a dashboard report.** Choose filters and add instructions when creating a report, so it focuses on the audience and data you need. [Export dashboard reports](/dashboards/how-to/export-dashboard-reports).

- **Take your results with you.** Export a chart as a PNG image or a table as a CSV file for use outside Supaboard.

- **Explore the data behind a result.** Dashboard filters now carry into drill-down views, and source labels help you see where the records came from. [Explore dashboard data](/dashboards/how-to/explore-dashboard-data).

- **Choose where an embedded dashboard opens.** Set its starting page and hide the page selector when viewers only need that view. [Embed a dashboard](/dashboards/embedding/overview).

## Fixed

- Chart axis edits now appear in the widget, and undoing or canceling dashboard edits restores the expected state.

- A new conversation appears in your chat list after its first message.
