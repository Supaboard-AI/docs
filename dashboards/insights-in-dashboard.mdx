Use an insight to understand what a widget shows, then follow up when you need a deeper explanation. Insights are most useful when you check their scope against the chart or table beside them.

## Before you begin

Open a dashboard you can access. Asking **Insight AI** questions requires **Can chat** access or higher. Wait for the relevant widgets to finish loading.

## Read a widget's insights

1. Find the chart, table, or KPI you want to understand.
2. Open **Insights and Info** on that widget.
3. Read the overview and the main findings.
4. Check the stated period, filters, and definitions against the widget.

A widget insight can include an **Overview**, individual **Insights**, and the **Scope** of the data used. It describes that widget's results; a claim about the whole business may need more supporting data.

## Ask Insight AI

Select **Insight AI** at the top of the dashboard to ask a question about its data. For example: “Which categories explain the decline?” or “Are returns grouped by order date or return date?”

Ask for a supporting table or breakdown when a conclusion needs checking. Continue in the same conversation so the question retains its context.

## Choose the right AI control

| You want to… | Use |
| --- | --- |
| Explain an existing number or trend | **Insight AI** |
| Add a chart, change a filter, or rearrange the dashboard | **Edit with AI** |
| Inspect source rows or break down a point yourself | [Records or Drill Through](/dashboards/how-to/explore-dashboard-data) |

## Expected result

You understand what the widget covers, which findings the data supports, and which questions still need investigation.
