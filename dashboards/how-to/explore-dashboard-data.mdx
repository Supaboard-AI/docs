Start with the number that needs explaining, then narrow the question. You can explore a dashboard without editing its layout.

## Before you begin

You need access to view the dashboard. **Insight AI** requires **Can chat** access or higher. Drill options depend on the widget's data and interaction settings.

## Set the scope

Read the dashboard's definitions and choose its filters first. A sales dashboard can use different dates for orders, returns, and refunds; check which date each control represents.

Use the same date range and category when comparing two widgets. If one total stays unchanged, it may be designed to ignore that filter or use a different source column.

## Inspect a chart or table

1. Hover over a chart point to read the value and series.
2. Right-click a chart point or table cell to see available actions.
3. Choose **Records** to inspect the rows behind the selected result.
4. Choose **Drill Through** to break a result down by a category or time column.
5. Use the drill view's breadcrumb to return to an earlier level.

The available columns come from the widget's query. A KPI can offer **Records** without offering every chart drill option.

If right-clicking offers **Filter by…**, it applies a value to an existing dashboard filter. It does not create a new filter. See [Filter from a table](/dashboards/filters/filter-dashboards-from-table-data).

## Ask a follow-up with Insight AI

Select **Insight AI** at the top of the dashboard and ask a focused question:

- “Which category explains most of the change in net revenue?”
- “What period does this return amount cover?”
- “Show the rows behind this unusual value.”

Check the explanation against the relevant widgets and ask for the underlying breakdown if the answer needs more support. Use **Edit with AI** when you want the dashboard itself changed.

## Expected result

You can explain the period, definition, and breakdown behind the number, or identify what needs clarification before using it in a decision.
